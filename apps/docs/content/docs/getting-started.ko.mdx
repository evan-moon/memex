## 설치

```bash
npm install -g @evan-moon/memex
```

## Claude Code 연결

```bash
memex mcp install
```

끝입니다. 최초 실행 시 임베딩 모델(~450 MB)이 `~/.memex/models/`에 한 번만 다운로드됩니다. 이후 실행은 완전히 오프라인으로 동작합니다.

## Claude Desktop 연결

`~/Library/Application Support/Claude/claude_desktop_config.json`에 다음을 추가하세요:

```json
{
  "mcpServers": {
    "memex": {
      "command": "node",
      "args": ["<`memex mcp path` 결과>"]
    }
  }
}
```

경로 확인:

```bash
memex mcp path
```

## 생성되는 파일

```
~/.memex/
  config.json     — 볼트 경로 및 설정
  memex.db        — SQLite DB (노트 + 임베딩 + FTS5)
  models/         — multilingual-e5-base 모델 캐시
```

노트는 볼트 디렉토리(기본값: `~/Documents/Second Brain`)에 일반 Markdown 파일로 저장됩니다. Obsidian과 완벽하게 호환됩니다.

## 볼트 경로 변경

```bash
memex config set vault-path ~/my-notes
```

## 설치 확인

```bash
memex list          # 최근 노트 목록 확인 (최초엔 비어 있음)
memex config show   # 현재 설정 확인
```

Claude에 memex를 연결한 뒤, 과거에 작업했던 내용에 대해 물어보세요. 과거 대화나 결정과 관련될 수 있는 주제라면, Claude가 자동으로 노트를 검색한 뒤 답변합니다.

## 기존 버전에서 업그레이드

업그레이드 후 첫 실행 시, memex는 멱등한 스키마 마이그레이션을 적용합니다 — 기존 노트에 `layer` 컬럼을 추가하고 (`projects` / `dev` / `herald` → `state`, `coding` → `rule`, 나머지 → `past`로 폴더 기반 백필), 플래시백 기능을 위해 `note_links`에 `source` 컬럼을 추가합니다. `memex classify`로 결과 분포를 확인하고, `memex relayer <id> <layer>`로 개별 노트를 정정할 수 있습니다.

각 레이어의 의미는 [노트 레이어](/ko/docs/layers) 페이지를 참조하세요.
