## 설치

```bash
npm install -g @evan-moon/memex
```

## 앱 연결하기

앱을 열고 **연결** 화면을 쓰세요:

```bash
memex ui
```

이 컴퓨터에 있는 MCP 클라이언트 — Claude, Claude Code, Codex, Cursor — 가 모두 보이고, 어떤 앱이 이미 memex에 닿을 수 있는지 알려줘요. 나머지는 버튼 하나로 등록돼요. 연결한 앱은 다시 켜야 적용돼요.

터미널에서 하려면:

```bash
memex mcp install
```

어느 쪽이든 각 클라이언트의 설정 파일에 직접 쓰고, 이미 들어 있던 다른 서버는 그대로 둬요. 옛 경로를 가리키는 클라이언트는 두 방법 모두 지금 경로로 맞춰줘요.

끝이에요. 최초 실행 시 임베딩 모델(~450 MB)이 `~/.memex/models/`에 한 번만 다운로드돼요. 이후 실행은 완전히 오프라인으로 동작해요.

## 생성되는 파일

```
~/.memex/
  config.json, 볼트 경로 및 설정
  memex.db, SQLite DB (노트 + 임베딩 + FTS5)
  models/, multilingual-e5-base 모델 캐시
```

노트는 볼트 디렉토리(기본값: `~/Documents/Second Brain`)에 일반 Markdown 파일로 저장됩니다. Obsidian과 완벽하게 호환됩니다.

## 볼트 경로 변경

```bash
memex config set vault-path ~/my-notes
```

## 설치 확인

```bash
memex list          # 최근 노트 목록 확인 (최초엔 비어 있음)
memex config show   # 현재 설정 확인
```

Claude에 memex를 연결한 뒤, 과거에 작업했던 내용에 대해 물어보세요. 과거 대화나 결정과 관련될 수 있는 주제라면, Claude가 자동으로 노트를 검색한 뒤 답변합니다.

## 기존 버전에서 업그레이드

업그레이드 후 첫 실행 시, memex는 멱등한 스키마 마이그레이션을 적용합니다, 기존 노트에 `layer` 컬럼을 추가하고 (`projects` / `dev` / `herald` → `state`, `coding` → `rule`, 나머지 → `past`로 폴더 기반 백필), 플래시백 기능을 위해 `note_links`에 `source` 컬럼을 추가합니다. `memex layer`로 결과 분포를 확인하고, `memex layer <id> <layer>`로 개별 노트를 정정할 수 있습니다.

각 레이어의 의미는 [노트 레이어](/ko/docs/layers) 페이지를 참조하세요.
