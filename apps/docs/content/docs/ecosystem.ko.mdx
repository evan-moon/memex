# Herald 패밀리

지금 보고 계신 건 **memex**, 작은 로컬 우선 도구 패밀리의 기억 계층 문서입니다. 셋은 하나의 원칙을 공유합니다 — **데이터는 당신의 기기에 남고, AI가 그쪽으로 온다.** 업로드도, 클라우드도, 계정도 없습니다.

## 세 도구, 하나의 스택

| 도구 | 무엇인가 | 무엇을 소유하나 |
| --- | --- | --- |
| **memex** — *현재 위치* | 영속 기억 | 노트와 그 맥락 — 모든 세션에 걸쳐 |
| **firma** | 금융 인텔리전스 | 포트폴리오 · 순자산 · 현금흐름 (`~/.firma/firma.db`) |
| **skope** | 뉴스 인텔리전스 | 세상을 보는 개인화 렌즈 — *나에게* 닿는 뉴스 |

각각은 따로 설치하는 독립 MCP 서버입니다. 서로에게 의존하지 않습니다 — 하지만 Claude가 셋을 동시에 들 수 있고, 바로 거기서 시너지가 납니다. memex는 지난달 firma에서 내린 결정을 기억하고, skope가 처음 띄운 이슈를 왜 따라가기 시작했는지 떠올려 줍니다.

## 페더레이션, 잠금이 아니라

도구들은 서로를 호출하지 않습니다. 각자 자기 데이터를 소유하고 자기 MCP 툴을 노출하며, 그 사이를 보는 건 오직 Claude뿐입니다. 어느 하나를 더하거나 빼도 나머지는 그대로 작동합니다. 이게 설계의 전부입니다 — **백엔드가 아니라 모델을 통해 결합한다.**

## 패밀리의 나머지 둘러보기

### firma — 당신의 돈

거래 내역을 Claude에 넣으면 전체 그림이 돌아옵니다 — 포트폴리오, 순자산, 현금흐름 — 로컬 SQLite 파일 하나에. 계정도, 클라우드도 없습니다.

[GitHub →](https://github.com/evan-moon/firma) · `npm install -g @evan-moon/firma`

### skope — 당신의 뉴스

세상을 보는 렌즈이자 감시자. Claude가 뉴스를 훑고, skope는 나에게 도달하는 경로가 있는 것만 남기며, 관심이 거품으로 좁아질 때 경고합니다.

[GitHub →](https://github.com/evan-moon/skope) · `npm install -g @evan-moon/skope`
