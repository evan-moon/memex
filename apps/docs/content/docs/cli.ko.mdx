## 노트 추가

```bash
memex add                                                     # 대화형 프롬프트 (layer 입력)
memex add --title "노트 제목" --content "..." --layer past
memex add --title "노트 제목" --file ./note.md --layer state
memex add --title "노트 제목" --content "..." --folder conversations/tom --layer past
memex add --title "노트 제목" --content "..." -T typescript -T architecture --layer past
```

`--layer`는 필수입니다. 회고/미팅/결정 기록은 `past`, 진행 중인 계획·로드맵은 `state`, Claude 행동 가이드는 `rule`을 선택합니다. 아래 [노트 레이어](#layers) 섹션 참조.

## 레이어

```bash
memex layer                               # past / state / rule 분포 확인
memex layer <id> state                     # 특정 노트의 layer 정정
```

인자 없이 실행하면 `memex layer`가 layer별 노트 수를 출력합니다, 첫 마이그레이션 직후 폴더가 어떻게 매핑됐는지 확인할 때 유용합니다. `<id> <layer>`를 주면 개별 노트를 정정합니다 (예: 로드맵 노트를 `past`에서 `state`로 이동).

## 검색

```bash
memex search "시맨틱 검색 쿼리"
memex search "지식 관리" --limit 10           # 다국어 검색
memex search "auth" --tag backend             # 태그로 필터링
memex search "auth" --from 2025-04-01         # 특정 날짜 이후 노트
memex search "auth" --from 2025-04-01 --to 2025-04-30
```

`--from`과 `--to`는 ISO 8601 날짜 형식(`YYYY-MM-DD`)을 받습니다. `--to`는 해당 날짜의 끝(23:59:59)까지 포함합니다.

## 탐색

```bash
memex list                  # 최근 노트 10개
memex list --limit 20
memex show <id>             # 노트 전체 내용 + 백링크
memex tags                  # 카운트 포함 전체 태그
memex related <id>          # 의미적으로 연관된 노트
```

## 다이제스트

```bash
memex digest                # 최근 7일간 저장된 노트 요약
memex digest --days 30      # 최근 30일
```

다이제스트는 노트를 폴더별로 그룹화해 태그·날짜와 함께 출력하고, 마지막에 **신호 요약**과 **active/stale 추론**을 덧붙입니다, 무엇을 썼는지와 무엇을 종합할 만한지를 한 번에 보는 주간 회고입니다.

## 인사이트 (신호 & 추론)

[추론 엔진](/ko/docs/inference-engine)은 노트 사이의 패턴을 찾아 가설로 승격시킵니다.

```bash
memex signals                       # 종합 안 된 패턴 탐지 + 나열
memex signals --type hidden_arc     # 한 종류만 (hidden_arc|stale_state|dangling_link|tag_burst)
memex signals --no-refresh          # 재탐지 없이 저장된 신호만 나열
memex signals dismiss <id>          # triage: 이 신호 다시 안 뜨게
memex signals snooze <id>

memex signals mint <signalId>               # 근거 번들 + 종합 프롬프트 출력 (읽기 전용)
memex signals mint <signalId> \             # 종합된 추론 저장
  --title "..." --summary "..." --confidence 0.7 --model claude-opus-4-8

memex inferences                    # 추론 목록 (먼저 staleness 재확인)
memex inferences archive <id>       # 아카이브 (출처용 보존, staleness에서 제외)
```

`mint`은 LLM을 안 쓰는 2단계 흐름입니다: `memex signals mint <id>`가 출처 노트와 종합 프롬프트를 모아주면, 당신(또는 Claude)이 추론을 써서 `--title`/`--summary`로 저장합니다. 추론은 모든 출처의 content 해시 스냅샷을 저장하므로, 나중에 출처 노트가 바뀌면 자동으로 `[!] STALE`로 전환됩니다.

탐지 임계값은 env로 조정합니다: `MEMEX_ARC_DIST`(기본 `0.45`), `MEMEX_ARC_MIN_MEMBERS`, `MEMEX_ARC_MAX_MEMBERS`, `MEMEX_ARC_MIN_SPAN_DAYS`, `MEMEX_STALE_DIST`, `MEMEX_STALE_MIN_NEWER`, `MEMEX_BURST_DORMANT_DAYS`, `MEMEX_BURST_MIN`.

## 스케줄

```bash
memex schedule                 # 일일 다이제스트용 cron/launchd 스니펫 출력
memex schedule --at 08:30      # 특정 시각
```

memex는 데몬을 돌리지 않습니다. `schedule`은 `memex digest`를 정해진 시각에 돌리는 cron 라인과 launchd plist를 복붙용으로 출력합니다, 스케줄링은 OS가 맡습니다. 탐지는 dirty-flag가 걸려 있어, 바뀐 게 없으면 예약 실행도 비용이 0입니다.

## 편집 & 삭제

```bash
memex edit <id>             # $EDITOR로 엽니다
memex delete <id>
memex delete --yes <id>     # 확인 프롬프트 생략
```

## 외부 볼트 (소스)

```bash
memex source add ~/Documents/My\ Notes    # 기존 볼트 등록
memex source list
memex source remove ~/Documents/My\ Notes
memex index                               # 볼트 + 모든 소스 스캔
memex index --force                       # 전체 재인덱싱
memex reembed                             # 현재 모델로 재임베딩
```

`source add`를 사용하면 기존 Obsidian 볼트나 Markdown 파일이 있는 폴더를 이동하지 않고 인덱싱할 수 있습니다.
