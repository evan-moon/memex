# 규칙이 실제로 도달하게 — 승인 요청서

> 운영 계약 memex #2280 §3에 따른 승인 요청서. 코드는 안 건드렸다.
> 시작은 하나의 실측이다 — **오늘 이 세션에서 House Rules는 한 글자도 도달하지 않았다.**

## 0. 실측 — 무엇이 어디서 잘리나

memex MCP가 붙은 이 세션의 시스템 프롬프트를 열어 봤다. memex 지침이 **2,018자에서 잘려 있다.**

```
받음   ## SEARCH             @ 89
받음   ## SAVE               @ 1,581
       ─────────────────────────── 잘린 지점 2,018
잘림   ## CORRECTIONS        @ 2,553      amends_kind · invalidates
잘림   ## RULE SCOPE         @ 3,902
잘림   ## FOLDER CONVENTION  @ 5,808
잘림   ## LINKS              @ 6,382
잘림   ## TAGS               @ 7,057
잘림   ## INSIGHTS           @ 7,380
                             baseInstructions 8,839
잘림   ## House Rules        16,361 전부
                             ─────────────────
                             합계 25,200 · 도달 8%
```

MCP `instructions`는 initialize 응답의 한 필드일 뿐이고, **모델에게 어떻게 보여줄지는
클라이언트가 정한다.** memex가 통제할 수 없다.

**이 문서가 뒤집는 것:** 같은 날 `rules.ts`의 주입 예산을 10,000 → 20,000으로 올렸다.
도움이 안 된다. 클라이언트가 2,018자에서 자르므로 **예산을 키울수록 버려지는 양만 늘어난다.**
원인은 memex의 예산이 아니었다.

## 1. 도달하는 경로는 무엇인가

| 경로 | 잘리나 | 밀어주나 | 지금 |
|---|---|---|---|
| MCP instructions | **잘림 (2,018자)** | 예 | 규칙이 여기 있다 |
| `~/.claude/CLAUDE.md` | 안 잘림 | 예 | 사람이 손으로 관리 |
| `~/.codex/AGENTS.md` | 안 잘림 | 예 | **비어 있음 — Codex는 규칙을 못 받는다** |
| auto-memory `MEMORY.md` | 안 잘림 | 예 | Claude Code 것, memex와 무관 |
| `recall` 훅 | 안 잘림 | 예 | **제목만** 넣는다 |
| `search_notes` | 안 잘림 | **아니오** | 규칙이 있는 줄 모르면 안 찾는다 |

마지막 줄이 볼트를 원본으로 두는 것의 한계다. **볼트는 읽힌다** — 마크다운 폴더이고 권한도
있다. 다만 규칙은 *찾아야 하는 줄 모르는 상태에서 지켜야 하는 것*이라 pull이 맞지 않는다.

에이전트가 기본으로 읽는 파일을 바이너리에서 뽑았다.

```
Claude Code   CLAUDE.md 274 · CLAUDE.local.md 27 · MEMORY.md 12 · AGENTS.md 10
Codex         AGENTS.md 77 · AGENTS.override.md 3        (CLAUDE.md는 안 읽음)
Aside         ~/.aside/u/0/AGENTS.md · SOUL.md · memory/{MEMORY,USER,TAXONOMY}.md
```

## 2. 스킬 — 필요할 때만 부르는 것이 왜 제일 싼가

이 기계의 스킬 40개를 쟀다.

```
설명(항상 로드)     13,656자
본문(부를 때 로드)  382,833자
                    ─────────
                    28배
```

`SKILL.md`의 frontmatter `description`만 항상 실리고 본문은 호출될 때 온다.
`ux-writing-kr`의 설명은 트리거 문구까지 적어 둔다 — *"이 버튼 뭐라고 쓸까", "토스트 문구",
"번역투 빼고"*. **언제 부를지를 설명이 들고, 무엇을 할지는 본문이 든다.**

규칙에 그대로 옮겨진다. `#2265`(블로그 초안 스킬, 3,919자)는 첫 줄이 이렇다.

> 주제나 키워드를 주면서 "블로그 초안 써줘", "내 문체로 써줘"라고 하면 이 스킬을 따른다.

**이미 트리거 조건이 적힌 스킬이다.** 그런데 지금은 매 세션 3,919자를 통째로 싣는다.

## 3. 세 갈래 — 규칙이 언제 필요한가

규칙을 성격으로 가르면 도달 경로가 따라 정해진다.

| 갈래 | 언제 필요한가 | 어디로 | 왜 |
|---|---|---|---|
| **항상** | 무엇을 하든 지켜야 함 | `CLAUDE.md`·`AGENTS.md`의 관리 블록 | 안 잘리고, 볼 수 있고, Codex도 받는다 |
| **쓸 때만** | 노트를 저장하는 순간 | `save_note` 응답 | 규칙이 필요한 바로 그 순간에 도달 |
| **부를 때만** | 사람이 그 일을 시킬 때 | 스킬 (`~/.claude/skills/`) | 설명만 상주, 본문은 호출 시 |

지금 승인된 7개를 갈라 보면 이렇다.

| id | 규칙 | 자수 | 갈래 |
|---:|---|---:|---|
| 2280 | memex 제품 설계 운영 계약 | 4,885 | **항상** (memex 작업 한정 — `scope: folder:` 후보) |
| 1440 | Evan 코드 스타일 가이드 (FP) | 3,437 | **항상** |
| 1442 | TypeScript 코딩 원칙 | 1,177 | **항상** |
| 1560 | memex 검색 규칙 (에이전트) | 477 | **항상** |
| 1559 | 노트 캡처 포맷 규칙 | 615 | **쓸 때만** |
| 1503 | 시장 분석 답변 규칙 v3 | 1,390 | **부를 때만** (firma 질문일 때) |
| 2265 | 스킬: 블로그 초안 쓰기 | 3,919 | **부를 때만** |
| 2283 | 레이어별 섹션 (승인 대기) | 1,617 | **쓸 때만** |
| 2284 | derives_from (승인 대기) | ~1,100 | **쓸 때만** |

항상 실릴 것은 **9,976자에서 5,706자로** 준다. 나머지는 필요한 순간에 온다.

## 4. 원본은 볼트에 남는다

내보내기는 원본을 옮기는 것이 아니라 **파생본을 만드는 것**이다. Aside가 자기 TAXONOMY.md
첫머리에 같은 불변식을 적어 뒀다.

> Semantic and episodic memory are **the source of truth**. L1 (`MEMORY.md`, `USER.md`)
> **is derived from them**. L1 files must stay small enough for prompt loading.

```
볼트의 rule 노트        ← 원본. 앱에서 고치고 승인한다
   │  (승인하는 순간 내보낸다)
   ├─▶ ~/.claude/CLAUDE.md   관리 블록
   ├─▶ ~/.codex/AGENTS.md    관리 블록
   └─▶ ~/.claude/skills/<slug>/SKILL.md
```

앱에서 고치는 것도, 승인 게이트도, `scope`도, 검색되는 것도 그대로다. 파생본은 지우고 다시
만들면 되는 캐시다.

**남의 파일에 쓴다는 것을 잊지 않는다.** `~/.claude/CLAUDE.md`에는 사람이 쓴 것이 있다.
마커 사이만 memex가 소유하고 바깥은 절대 건드리지 않는다.

```
<!-- memex:rules start -->
... 여기만 memex가 쓴다 ...
<!-- memex:rules end -->
```

`연결`(`/connect`) 화면이 이미 `~/.claude.json`과 `~/.codex/config.toml`을 감지해 MCP를
등록한다. **쓸 자리를 이미 알고 있다.**

## 5. 먼저 채워야 하는 것 — `scope`

내보내기는 `scope`를 읽어야 무엇을 어디로 보낼지 정할 수 있다. 지금 값이 있는 것은
`#2280` 하나뿐이고 나머지 여섯은 비어 있다. 그리고 지금의 `scope`로는 3절의 세 갈래를
표현할 수 없다.

| 지금 | 표현되나 |
|---|---|
| `global` | 항상 ✅ |
| `folder:<path>` | 항상, 그 폴더 안에서 ✅ |
| `tag:<name>` | 항상, 그 태그에서 ✅ |
| — | **쓸 때만** ❌ |
| — | **부를 때만** ❌ |

`scope`는 "어디서"만 말하고 "언제"는 못 말한다. **`when`을 하나 늘리는 것이 이 작업의
핵심 결정이다** — `always` (기본) · `writing` · `invoked`.

`invoked`인 규칙은 스킬로 나가고, 트리거 문구가 필요하다. `#2265`는 이미 첫 줄에 갖고 있다.

## 6. CLAUDE.md 재검토 — 계속 들고 다닐 것인가

프로젝트 `CLAUDE.md` 9,901자를 섹션별로 쟀다.

| 섹션 | 자수 | 판정 |
|---|---:|---|
| Architecture | 1,329 | **남긴다.** 어느 패키지가 무엇인지는 첫 질문에 필요하다 |
| Working on the UI | 3,014 | **덜어낸다.** `yarn dev:app`·ABI·빌드 체인 — UI를 만질 때만 필요하다. 서브디렉토리 `apps/CLAUDE.md`로 내리거나 스킬로 |
| Who this is for | 882 | **남긴다.** 누구를 위한 제품인지는 모든 판단에 붙는다 |
| Surface policy | 1,836 | **남긴다.** "CLI를 늘리지 마라"는 늘리려는 순간 전에 알아야 한다 |
| Memex MCP Usage | 2,721 | **옮긴다.** 두 규칙(#2283·#2284)이 승인되면 볼트로 가고 이 절은 사라진다 |

**3,014자가 UI 작업에만 필요한 내용이다.** 매 세션 싣고 있다. Claude Code는 하위 디렉토리의
`CLAUDE.md`를 그 디렉토리 파일을 만질 때 읽으므로, `apps/ui/CLAUDE.md`로 내리면 필요할 때만
온다. 스킬로 만들 수도 있으나 디렉토리 규칙이 더 싸다.

전역 `~/.claude/CLAUDE.md`(4,979자)는 그대로 둔다. 그 자체가 `#1440`의 스냅샷이고,
내보내기가 생기면 **memex가 그 자리를 대신 채우게 된다.**

## 7. 구현 범위

| 하는 것 | 안 하는 것 |
|---|---|
| `when` 하나 늘리기 (`always`/`writing`/`invoked`) | 새 레이어 · 새 노트 타입 |
| 승인된 규칙 7개에 `scope`·`when` 채우기 | 규칙 본문 다시 쓰기 |
| `CLAUDE.md`·`AGENTS.md` 관리 블록 내보내기 | 마커 바깥 건드리기 |
| `writing` 규칙을 `save_note` 응답에 싣기 | `recall`에 규칙 싣기 (필요하면 나중에) |
| `invoked` 규칙을 `SKILL.md`로 내보내기 | 스킬 자동 생성 품질 보장 |
| `Working on the UI`를 `apps/ui/CLAUDE.md`로 | 나머지 섹션 재배치 |
| 주입 예산 20,000 되돌리기 | |

마지막 줄이 중요하다. **오늘 올린 예산은 원인을 잘못 짚은 것이므로 되돌린다.** 잘리는 경로에
더 밀어 넣는 것은 아무것도 고치지 않는다.

## 8. 검증할 실제 상태

1. 내보낸 뒤 **새 세션의 시스템 프롬프트에 규칙이 실제로 있는가** — 오늘 한 것과 같은
   방법으로 시스템 프롬프트를 열어 확인한다. 테스트 통과로는 확인되지 않는다
2. `~/.claude/CLAUDE.md`의 마커 **바깥이 한 글자도 안 바뀌었는가**
3. Codex 세션에서 규칙이 도달하는가 — 지금은 0이다
4. `writing` 규칙이 `save_note` 응답에 오고, 그 뒤 저장이 규칙을 지키는가
5. 스킬로 나간 `#2265`가 "블로그 초안 써줘"에 실제로 불려 나오는가
6. 규칙을 앱에서 고치면 파생본이 따라 바뀌는가
7. 볼트가 없거나 파일이 읽기 전용일 때 내보내기가 조용히 실패하지 않는가

## 9. 승인이 필요한 것

1. `when` 축을 늘리는 것 (`always` · `writing` · `invoked`)
2. 승인 순간에 `CLAUDE.md`·`AGENTS.md`의 마커 블록으로 내보내는 것
3. `invoked` 규칙을 `~/.claude/skills/`로 내보내는 것
4. `Working on the UI` 3,014자를 `apps/ui/CLAUDE.md`로 내리는 것
5. 오늘 올린 주입 예산 20,000을 되돌리는 것
