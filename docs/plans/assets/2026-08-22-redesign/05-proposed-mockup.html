3. 이 문제를 가장 잘 푸는 앱들

앱 / 분야훔칠 것측정된 효과
ASReview
체계적 문헌고찰 스크리닝 · Nature MI 2021		 능동학습 우선순위 큐. 사람은 oracle, 기계는 순위만. “충분히 봤다”고 판단되면 중단 스크리닝 부하 최대 95% 감소
독립 검증 연구에선 평균 60.2%
TAR / CAL
법률 e-Discovery · Cormack & Grossman SIGIR 2014		 백만 건을 다 안 읽고 높은 recall에 도달. 전수 검토를 포기하는 것이 정답이라는 증명 이 분야 표준 방법론으로 정착
Prodigy
주석 도구 (Explosion)		 가능한 가장 작은 질문으로 쪼개기. 이진 결정 + 키보드 + 모델 인더루프 —
Snorkel
약한 지도학습 · arXiv 1711.10160		 한 건씩 라벨링 대신 규칙(labeling function)을 써서 한 번에 수천 건 처리 전문가 모델 구축 2.8배 빠름, 예측성능 평균 +45.5%
Dependabot
GitHub		 사유를 붙여 기각(오탐 / 테스트에서만 씀 / 안 고침). 기각도 데이터로 남음 —
Renovate
Dependency Dashboard		 연관 항목을 그룹으로 묶어 한 PR로. 승인 워크플로 내장 —
Sentry
이슈 트리아지		 이벤트 그룹핑 + suspect commit(원인 후보를 기계가 지목) + 실행가능성 기준 우선순위 새 그룹핑 모델로 중복 이슈 20% 추가 차단, 오병합 절반
Anki / FSRS 항목별 다음 검토일. 카운터가 아니라 오늘 치 큐 동일 유지율에서 일일 복습량 약 25% 감소
공통점 하나. 이 중 어느 것도 사람에게 원문 전체를 읽히지 않아. ASReview는 초록만, Sentry는 의심 커밋 한 줄, Dependabot은 CVE 한 줄, Anki는 카드 앞면 한 줄. 기계가 읽고, 사람은 판정만 한다. memex는 지금 그 반대야.
