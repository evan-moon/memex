# Reranker 추가 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** memex `search_notes`가 top-K(보통 5)를 곧장 LLM에 넘겨 "Lost in the Middle" 위험이 있는 현재 구조를, **retrieve top-50 → cross-encoder rerank → top-5** 의 2단계로 바꾼다. 답변 품질 15-30% ↑가 업계 표준 결과.

**Architecture:** bi-encoder(`e5-base`)가 던진 거친 후보군을 cross-encoder(`bge-reranker-v2-m3`)가 query+passage 쌍 단위로 다시 채점. ONNX q8 양자화된 모델을 `@huggingface/transformers` 의 `text-classification` 파이프라인으로 로컬 추론. **embed와 다른 모델 클래스 + 다른 입력 형태**라 별도 패키지(`packages/rerank`)로 분리. db 레이어는 reranker를 모르고, **service 레이어에서 rerank**(coupling 최소화).

**Out of scope:**
- Cohere API 등 원격 reranker (local-first 원칙 위배)
- Reranker 모델 다운로드 UX (현재 e5-base와 동일 캐시 방식 재사용)
- RAGAS 정식 통합 (간이 평가 스크립트만)

**Tech Stack:** TypeScript, `@huggingface/transformers` v3.5, ONNX q8, vitest, tsup.

**Step 3: 최소 구현**

```ts
// packages/rerank/src/index.ts
import { pipeline, env, AutoTokenizer, AutoModelForSequenceClassification } from '@huggingface/transformers';

const MODEL = 'Xenova/bge-reranker-v2-m3';

export type Reranker = (query: string, passages: string[]) => Promise<number[]>;

export const createReranker = async (modelCacheDir: string): Promise<Reranker> => {
  env.cacheDir = modelCacheDir;
  const tokenizer = await AutoTokenizer.from_pretrained(MODEL);
  const model = await AutoModelForSequenceClassification.from_pretrained(MODEL, { dtype: 'q8' });

  return async (query: string, passages: string[]): Promise<number[]> => {
    if (passages.length === 0) return [];
    const pairs = passages.map((p) => [query, p] as [string, string]);
    const inputs = tokenizer(pairs, { padding: true, truncation: true });
    const { logits } = await model(inputs);
    const data = logits.data as Float32Array;
    return Array.from(data);
  };
};
```

**Files:**

**Step 1: 두 service의 `semanticSearch` 시그니처 변경**

기존:
```ts
export const semanticSearch = async (
  client, embedder, query, limit, category?, tag?, dateFrom?, dateTo?,
) => { ... }
```

변경:
```ts
import type { Reranker } from '@memex/rerank';

export const semanticSearch = async (
  client: MemexClient,
  embedder: Embedder,
  reranker: Reranker | null,
  query: string,
  limit: number,
  category?: string,
  tag?: string,
  dateFrom?: number,
  dateTo?: number,
) => {
  const overfetch = reranker ? Math.min(50, limit * 10) : limit;
  const embedding = await embedder(query, 'query');
  const candidates = dbSearchNotes(client, query, embedding, overfetch, category, tag, dateFrom, dateTo);

  if (!reranker || candidates.length <= limit) return candidates.slice(0, limit);

  const scores = await reranker(query, candidates.map((c) => `${c.title}\n\n${c.content}`));
  return candidates
    .map((note, i) => ({ ...note, distance: -scores[i] }))
    .sort((a, b) => a.distance - b.distance)
    .slice(0, limit);
};
```
