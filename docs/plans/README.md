# Plans

A record of decisions, not a roadmap. Each document says what was true and what was decided on the
day it was written, and nothing here is rewritten afterwards.

Two things to know before reading one:

- **The desktop app is retired (2026-09-20).** memex has no window, no editor and no screen. Some
  of these documents were written while it did, and mention screens, cards or an app. Read those
  passages as history. The documents written *for* the app were deleted with it.
- **memex is a memory engine reached over MCP.** Anything that needs a person to read, curate or
  clear a queue is the wrong design, whatever an older document here proposes.

`../../CLAUDE.md` is the current statement of what memex is.
