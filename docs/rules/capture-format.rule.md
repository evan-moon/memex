노트를 저장할 때 검색이 잘 되도록 다음 포맷을 지킨다.

- 제목은 내용을 식별하는 명사구로 쓴다. 날짜만/세션명만 된 제목은 금지. 예: "Firma 통화 3-line 규칙 결정"(O), "Firma 작업 세션 2026-05-03"(X). 제목은 검색에서 ×2 가중이고 임베딩 신호라, 제목이 비면 검색에서 사실상 사라진다.
- 첫 문단은 TL;DR 한두 줄로 노트의 핵심을 먼저 적는다. 임베딩과 미리보기의 가장 강한 신호가 첫머리에 오게 한다.
- 한 노트 = 한 주제(atomic). 주제가 여러 개면 노트를 쪼개고 [[다른 노트]]로 연결한다. 멀티토픽 노트는 벡터가 흐려져 검색 정밀도가 떨어진다.
- 사람·프로젝트·기술 등 엔티티는 일관된 이름을 쓰고, 가능하면 [[위키링크]]로 잇는다. 링크 그래프가 link-expansion 검색을 강화한다.
- 레이어를 정확히: 일어난 일의 기록은 past, 현재 상태·계획은 state. (state 노트는 최신 편집일이 검색 가산점이 되므로 갱신 시 실제로 수정한다.)
