memex를 검색할 때(에이전트로서) 다음을 따른다.

- 중요하거나 모호한 질문은 한 번의 검색으로 끝내지 않는다. 표현을 바꿔 2~3회 검색한다: (a) 사용자 언어 + 영어, (b) 사용자 워딩 + 그 밑의 개념. 짧은 키워드가 긴 문장보다 잘 맞는다.
- 시점이 있으면 date_from/date_to를, 주제가 좁으면 tag/category 필터를 적극 쓴다.
- 검색 전에 "이 대화에 빠진 맥락이 무엇인가"를 먼저 한 줄로 정한 뒤 그것을 쿼리로 만든다. 결과를 통째로 맥락에 붓지 말고, 질문에 실제로 관련된 노트만 추려 인용한다.
- 한 번에 못 찾으면 표현을 바꿔 다시 시도한다. "결과 없음"을 곧바로 "기록이 없다"로 단정하지 않는다.
